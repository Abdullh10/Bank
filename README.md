# منصة بنك أسئلة كيمياء 2-1

منصة عربية (RTL) لتحليل أهداف مقرر **كيمياء 2-1** (الصف الثاني الثانوي – مسارات – الفصل الدراسي الأول) وبناء بنك أسئلة مرتبط بكل هدف.

البنية: المقرر ← الفصول ← الدروس ← الأهداف ← الأسئلة (7 اختيار من متعدد + 3 مقالية لكل هدف افتراضيًا).

## التقنيات
- **الخادم:** Node.js 22.13 أو أحدث + Express.
- **قاعدة البيانات:** SQLite عبر الوحدة المدمجة `node:sqlite`، في ملف واحد (`data/chem21.db`) على الخادم. البيانات لا تُحفظ في المتصفح، فتبقى متاحة بعد الخروج ومن أي جهاز يصل إلى الخادم.
- **الواجهة:** HTML و CSS و JavaScript (وحدات ES) دون أدوات بناء، مع خط IBM Plex Sans Arabic.
- **المصادقة:** حسابات بأدوار (مشرف `admin`، ومراجع `reviewer`، ومعلم للاطلاع `viewer`). كلمات المرور مجزأة بـ scrypt، والجلسات في ملف تعريف ارتباط HttpOnly، ولا توجد أي مفاتيح سرية في الواجهة.

## التشغيل محليًا
```bash
npm install
npm run seed                                   # يستورد الفصول والدروس والأهداف والمحتوى المكمّل والأسئلة من data/
npm run create-user -- admin1 admin "اسم المشرف"   # يطلب كلمة المرور (10 أحرف على الأقل)
npm start                                      # http://localhost:3000
npm test                                       # اختبارات الواجهة البرمجية
```
- يمكن تمرير كلمة المرور عبر المتغير `USER_PASSWORD` بدل إدخالها تفاعليًا.
- `npm run seed` آمن للتكرار: يضيف الجديد فقط، ولا يمس قرارات الاعتماد ولا تعديلات المراجعين.

## الوصول
المنصة مغلقة: أول صفحة هي صفحة الدخول، ولا يظهر أي محتوى إلا لحساب مفعّل (`viewer` أو `reviewer` أو `admin`).
- **الحماية في قاعدة البيانات:** سياسات RLS والدوال المحمية في Supabase ترفض أي قراءة من غير المسجلين، فالحماية لا تعتمد على الواجهة وحدها.
- **نسخة العرض الثابتة:** حُذفت لأنها كانت تكشف الإجابات للزوار.
- **سجل Git:** نسخ قديمة من ملفات العرض ما زالت في سجل المستودع.

## حساب الطالب
تدريب ذاتي فقط، والتفاصيل في [`docs/supabase-setup.md`](docs/supabase-setup.md#حساب-الطالب-التدريب-فقط).
- **الواجهة:** `public/student.js` لصفحات الطالب، و`public/staff.js` لتقدم الطلاب وإدارة حساباتهم.
- **إنشاء الحسابات:** عبر دالة الحافة `supabase/functions/admin-users`.
- **العمل في وضع Supabase فقط:** الخادم المحلي لا يدعم حسابات الطلاب.

## التشغيل على Supabase (قاعدة بيانات ودخول حقيقيان)
الواجهة على GitHub Pages، وقاعدة البيانات وتسجيل الدخول على Supabase. الخطوات في [`docs/supabase-setup.md`](docs/supabase-setup.md).
- **ترتيب اختيار الوضع:**
  1. خادم محلي (`api/`) إن وُجد.
  2. Supabase إن ضُبط `public/config.js`.
  3. نسخة العرض الثابتة.
- **الملفات:**
  - `supabase/schema.sql`: الجداول وسياسات RLS والدوال المحمية.
  - `supabase/seed/*.sql`: البيانات، وتُولد بالأمر `npm run build-supabase-seed`.
  - `public/supa.js`: طبقة الربط.

## النشر
يحتاج النشر إلى خادم يشغّل Node.js 22.13 أو أحدث مع **قرص دائم** لملف قاعدة البيانات، مثل خادم VPS أو Render أو Railway أو Fly.io مع وحدة تخزين دائمة.
- `PORT`: منفذ الخادم.
- `DB_PATH`: مسار ملف قاعدة البيانات على القرص الدائم.
- `COOKIE_SECURE=1`: يُفعَّل عند التشغيل خلف HTTPS.
- **النسخ الاحتياطي:** انسخ ملف `DB_PATH` دوريًا. ويمكن أيضًا تصدير الأسئلة والأهداف بصيغة CSV من صفحة بنك الأسئلة.

## التحديث
1. `git pull`
2. `npm install`
3. `npm run seed` لإضافة أي أهداف أو أسئلة جديدة وُضعت في `data/`
4. أعد تشغيل الخادم.

## ملفات البيانات (`data/`)
| الملف | المحتوى |
|---|---|
| `objectives_original.json` | الأهداف الأصلية حرفيًا، وتغطية المذكرة لكل هدف، وقرارات المستخدم |
| `objective_reviews.json` | المراجعة الآلية لصياغة الأهداف وتصنيفها (مقترحات غير معتمدة) |
| `supplements.json` | محتوى مكمّل لفراغات المذكرة، أعده الوكيل الكيميائي التربوي (غير معتمد) |
| `questions/<رمز الهدف>.json` | أسئلة الهدف (مسودات مولدة) |

## التقارير
التقارير في `docs/`: خريطة المقرر، ومراجعة المذكرة، وفهرس صفحاتها، وتقرير النموذج الأولي.
