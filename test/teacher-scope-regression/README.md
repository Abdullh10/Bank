# اختبار انحدار «نطاق المعلم»: لا يتغير شيء لغير المعلم، ولا يُمسّ تقدم الطلاب

الفكرة: نقارن مخرجات دوال القراءة (لكل دور) على قاعدتين: واحدة بمخطط ما قبل التحديث، وأخرى بعد تنفيذ `supabase/schema.sql` الجديد، على بيانات تدريب حقيقية. المسموح أن يختلف فقط ما يخص المعلم (قائمة مقرراته).

1. قاعدة `oldx` بمخطط ما قبل التحديث مع بيانات المحتوى، وتنفيذ `seed.sql` (مستخدمون بكل الأدوار وجلسات تدريب وإجابات).
2. `newx` نسخة منها بعد تنفيذ `supabase/schema.sql` الجديد.
3. على كل قاعدة: `compare-helper.sql` ثم `compare.sql`، واحفظ المخرجات وقارنها بـ `diff`.
4. تأكد أن بصمة `practice_answers` و`practice_sessions` واحدة قبل التحديث وبعده.

نتيجة 2026-10-18: 274 مقارنة، الفروق الوحيدة قائمة مقررات المعلم (لا يرى المقررات «قيد الإعداد»)؛ وبصمة جداول التدريب متطابقة (11 جلسة و77 إجابة).
