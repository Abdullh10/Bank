# محتوى «الاستعداد للتحصيلي»

مقرر من نوع `tahsili` (المقرر 5) على البنية نفسها لبقية المقررات:

| المستوى | في القسم | المعرّف |
|---|---|---|
| الفصل | المادة: 1 الأحياء والبيئة، 2 الكيمياء، 3 الفيزياء، 4 الرياضيات | 501–504 |
| الدرس | الوحدة (1–99) | 50000 + 100×المادة + الوحدة |
| الهدف | الموضوع داخل الوحدة | 5000000 + 10000×المادة + 100×الوحدة + الموضوع |

الأسئلة كلها **اختيار من متعدد بأربعة بدائل** (تفرضه قاعدة البيانات لأسئلة هذا المقرر).

## الملفات
- `units.json`: المواد ووحداتها وموضوعات كل وحدة. **رقم الوحدة ثابت** بعد رفعها لأن منه معرّفها.
  - الوحدات مرتبة حسب الصف، وعنوان الوحدة يبدأ بصفها («أول ثانوي · …»)، فتظهر للطالب مجمعة تحت عناوين الصفوف.
  - الكيمياء: أول ثانوي 1–5، وثاني ثانوي 6–26، وثالث ثانوي 27–32.
  - الوحدة التي تُحذف من الملف تُحذف من المنصة عند التوليد التالي إن لم يكن فيها أسئلة، وإلا تبقى.
  - 99 «مراجعة شاملة» في كل مادة للأسئلة التي لم تُصنَّف في وحدة بعد.
- `questions/<المادة>-<الوحدة>.json`: أسئلة وحدة واحدة، مثل `questions/2-7.json` (الكيمياء، ثاني ثانوي، التوزيع الإلكتروني).

```json
{
  "meta": { "source": "تجميعات 1447 (بعد المراجعة والتعديل)" },
  "questions": [
    {
      "topic": 1,
      "stem": "ما طاقة فوتون تردده $5.0\\times10^{14}\\,\\text{Hz}$؟",
      "options": ["$3.3\\times10^{-19}\\,\\text{J}$", "…", "…", "…"],
      "correct_index": 0,
      "explanation": "$E = h\\nu = …$",
      "distractor_notes": ["", "سبب خطأ ب", "سبب خطأ ج", "سبب خطأ د"],
      "thinking_level": "تطبيق",
      "difficulty": "متوسط",
      "question_kind": "حساب",
      "source_ref": "اختياري: مصدر السؤال",
      "images": [{ "src": "qimg/tahsili/phys-12.png", "alt": "وصف الشكل" }]
    }
  ]
}
```

- `topic` اختياري (الافتراضي 1).
- `correct_index` من 0 إلى 3، وملاحظة البديل الصحيح في `distractor_notes` فارغة، وكل بديل خاطئ له سبب.
- `thinking_level`: تذكر، فهم، تطبيق، تحليل، تقويم، إبداع. و`difficulty`: سهل، متوسط، صعب.
- الرموز الرياضية بين `$…$` أو `$$…$$` (انظر `docs/supabase-setup.md`)، وكل `$` له نظير.
- الصور في `public/qimg/tahsili/` ويُشار إليها بالمسار `qimg/tahsili/…`.
- **الترقيم بالترتيب داخل الموضوع:** أضف الجديد في آخر الملف، ولا تحذف سؤالًا رُفع ولا تعيد ترتيب الأسئلة (يُعدَّل السؤال المرفوع من المنصة).

## التوليد والرفع
```bash
node scripts/build-tahsili-seed.js --check   # الفحص فقط
node scripts/build-tahsili-seed.js           # يكتب supabase/seed-tahsili/*.sql
```
ثم نفّذ ملفات `supabase/seed-tahsili/` بالترتيب في SQL Editor (بعد `schema.sql`). التنفيذ آمن للتكرار: السؤال الموجود لا يُكرر ولا يُستبدل.
الأسئلة تُرفع بحالة «مولدة»، ويعتمدها المراجع من المنصة قبل أن تظهر للطلاب.
